# Week 1: Java Basics Study Plan

## Daily Schedule (1-2 hours)
- **30 min**: Concept learning (reading/watching)
- **60 min**: Hands-on coding practice
- **15 min**: Review and notes
- **15 min**: Break/flexible time

## Day 1: Setting Up & First Program
### Learning Objectives:
- Install/set up Java development environment
- Write, compile, and run first Java program
- Understand basic Java program structure

### Activities:
1. [ ] Verify Java installation (already done: `java -version`)
2. [ ] Choose and set up IDE (IntelliJ IDEA Community/Eclipse/VS Code)
3. [ ] Create HelloWorld.java program (completed above)
4. [ ] Experiment with modifications:
   - Print multiple lines
   - Print your name
   - Print numbers
5. [ ] Read about Java syntax basics

### Resources:
- Oracle Java Tutorials: "Getting Started"
- Hello World program analysis

### Practice Problems:
1. Modify HelloWorld to print your name 5 times
2. Create a program that prints:
   ```
   *
   **
   ***
   ****
   ```
3. Create a program that calculates and prints the sum of two numbers

## Day 2: Variables and Data Types
### Learning Objectives:
- Understand Java primitive data types
- Learn variable declaration and initialization
- Practice type casting

### Activities:
1. [ ] Learn about 8 primitive types: byte, short, int, long, float, double, boolean, char
2. [ ] Practice declaring variables of each type
3. [ ] Learn about literals and variable naming conventions
4. [ ] Practice type casting (implicit and explicit)
5. [ ] Learn about String class (though not primitive)

### Resources:
- Java Primitive Data Types tutorial
- Variable naming conventions

### Practice Problems:
1. Create variables of each primitive type and print their values
2. Demonstrate type casting: int to double, double to int (discuss precision loss)
3. Create a program that converts Celsius to Fahrenheit
4. Create a program that swaps two numbers (with and without temp variable)

## Day 3: Operators
### Learning Objectives:
- Master arithmetic, relational, and logical operators
- Understand operator precedence
- Practice compound assignment operators

### Activities:
1. [ ] Arithmetic operators: +, -, *, /, %
2. [ ] Relational operators: ==, !=, >, <, >=, <=
3. [ ] Logical operators: &&, ||, !
4. [ ] Bitwise operators (brief introduction)
5. [ ] Assignment operators: =, +=, -=, *=, /=, %=
6. [ ] Unary operators: ++, --, +, -, !
7. [ ] Ternary operator: ? :

### Resources:
- Java Operators guide
- Operator precedence chart

### Practice Problems:
1. Create a calculator that performs basic arithmetic operations
2. Create a program that determines if a number is even or odd
3. Create a program that finds the largest of three numbers
4. Create a program that checks if a year is leap year
5. Practice operator precedence with complex expressions

## Day 4: Control Flow - Conditional Statements
### Learning Objectives:
- Use if-else statements effectively
- Implement switch statements
- Practice nested conditions

### Activities:
1. [ ] Simple if statements
2. [ ] if-else statements
3. [ ] if-else-if ladder
4. [ ] Nested if statements
5. [ ] Switch statements (with break, default)
6. [ ] Comparing if-else vs switch

### Resources:
- Java Control Flow Statements tutorial

### Practice Problems:
1. Create a grading system (A-F based on score)
2. Create a basic calculator using switch statement
3. Create a program that checks if a character is vowel or consonant
4. Create a program that determines the number of days in a month
5. Create a program that simulates a simple menu-driven interface

## Day 5: Control Flow - Loops
### Learning Objectives:
- Master for, while, and do-while loops
- Understand loop control statements (break, continue)
- Practice nested loops

### Activities:
1. [ ] For loop syntax and usage
2. [ ] While loop syntax and usage
3. [ ] Do-while loop syntax and usage
4. [ ] Loop control: break and continue
5. [ ] Nested loops
6. [ ] Infinite loops and prevention

### Resources:
- Java Loops tutorial
- Common loop patterns

### Practice Problems:
1. Print numbers from 1 to 100 using all three loop types
2. Print even numbers between 1 and 50
3. Calculate factorial of a number
4. Print Fibonacci series up to n terms
5. Print patterns:
   - Right triangle
   - Pyramid
   - Number patterns
6. Create a program that finds prime numbers in a given range

## Day 6: Methods/Functions
### Learning Objectives:
- Understand method declaration and invocation
- Learn about parameters and return values
- Practice method overloading
- Understand scope and lifetime of variables

### Activities:
1. [ ] Method syntax: modifiers, return type, name, parameters
2. [ ] Void methods vs methods returning values
3. [ ] Parameter passing (by value)
4. [ ] Method overloading (same name, different parameters)
5. [ ] Recursion introduction (simple examples)
6. [ ] Static vs instance methods (brief)

### Resources:
- Java Methods tutorial
- Parameter passing in Java

### Practice Problems:
1. Create methods for basic arithmetic operations (add, subtract, multiply, divide)
2. Create a method that checks if a number is prime
3. Create overloaded methods to calculate area of different shapes
4. Create a recursive method to calculate factorial
5. Create a method that reverses an array
6. Create utility methods for string manipulation

## Day 7: Arrays
### Learning Objectives:
- Understand array declaration, initialization, and usage
- Learn about multidimensional arrays
- Practice common array operations
- Understand ArrayIndexOutOfBoundsException

### Activities:
1. [ ] Declaration and initialization of arrays
2. [ ] Accessing array elements
3. [ ] Array length property
4. [ ] Looping through arrays
5. [ ] Multidimensional arrays (2D focus)
6. [ ] Common algorithms: search, min/max, sum, reverse
7. [ ] Arrays class utility methods (brief introduction)

### Resources:
- Java Arrays tutorial
- Common array algorithms

### Practice Problems:
1. Create an array of integers and print all elements
2. Find the largest and smallest element in an array
3. Calculate the average of array elements
4. Search for an element in array (linear search)
5. Reverse an array
6. Create a 2D array and print it in matrix format
7. Transpose a 2D matrix
8. Implement bubble sort on an array

## Weekly Review & Assessment
### End-of-Week Checklist:
- [ ] Can write, compile, and run Java programs independently
- [ ] Comfortable with all primitive data types
- [ ] Can use operators correctly in expressions
- [ ] Can implement conditional logic with if/else and switch
- [ ] Can use all three loop types appropriately
- [ ] Can write and invoke methods with parameters and return values
- [ ] Can declare, initialize, and manipulate arrays
- [ ] Understands basic debugging techniques

### Reflection Questions:
1. What concepts felt easiest to grasp?
2. What concepts were most challenging?
3. Which practice problems took the most time?
4. What would you like to review more deeply?
5. How confident do you feel about writing simple Java programs?

### Next Steps Preparation:
- Review any challenging concepts from Week 1
- Prepare for Week 2: Object-Oriented Programming
- Set up practice environment for OOP concepts

Let's start with Day 1! Remember to code along as you learn - the best way to learn programming is by doing.
