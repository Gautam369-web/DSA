# DSA Learning Path for Java Beginners (Target: Coding Interviews)

## Current Status
- **Programming Background**: Complete beginner (never coded)
- **Goal**: Prepare for coding interviews
- **Time Commitment**: 1-2 hours daily
- **Language**: Java (starting from scratch)

## Phase 1: Java Fundamentals (Weeks 1-2)
**Goal**: Build strong foundation in Java syntax and OOP concepts

### Week 1: Java Basics
- [ ] Variables and Data Types
- [ ] Operators (Arithmetic, Logical, Comparison)
- [ ] Control Flow (if/else, switch)
- [ ] Loops (for, while, do-while)
- [ ] Methods/Functions
- [ ] Arrays
- [ ] String manipulation
- [ ] Basic I/O (Scanner, System.out)

### Week 2: Object-Oriented Programming
- [ ] Classes and Objects
- [ ] Constructors
- [ ] Encapsulation (getters/setters)
- [ ] Inheritance
- [ ] Polymorphism (method overriding/overloading)
- [ ] Abstraction (abstract classes, interfaces)
- [ ] Packages and imports
- [ ] Exception handling (try-catch)

## Phase 2: Core Data Structures (Weeks 3-6)
**Goal**: Master essential data structures with Java implementations

### Week 3: Arrays & Strings
- [ ] Array operations (traversal, insertion, deletion, search)
- [ ] 2D arrays
- [ ] StringBuilder/StringBuffer
- [ ] String manipulation algorithms
- [ ] Practice: LeetCode Easy array/string problems

### Week 4: Linked Lists
- [ ] Singly Linked List implementation
- [ ] Doubly Linked List implementation
- [ ] Operations (insertion, deletion, traversal, reversal)
- [ ] Cycle detection (Floyd's algorithm)
- [ ] Practice: LeetCode Medium linked list problems

### Week 5: Stacks & Queues
- [ ] Stack implementation (array & linked list)
- [ ] Queue implementation (array & linked list)
- [ ] Applications (parentheses validation, BFS)
- [ ] Practice: LeetCode stack/queue problems

### Week 6: Recursion & Backtracking
- [ ] Recursion fundamentals
- [ ] Base case and recursive case
- [ ] Tail recursion
- [ ] Backtracking principles
- [ ] Practice: Subset, permutation, combination problems

## Phase 3: Advanced Data Structures & Algorithms (Weeks 7-10)
**Goal**: Learn complex structures and algorithmic techniques

### Week 7: Trees
- [ ] Binary Tree implementation
- [ ] Tree traversals (inorder, preorder, postorder, level-order)
- [ ] Binary Search Tree (BST) properties
- [ ] BST operations (insert, delete, search)
- [ ] Practice: Tree problems on LeetCode

### Week 8: Heaps & PriorityQueue
- [ ] Min-Heap and Max-Heap implementation
- [ ] Java PriorityQueue class
- [ ] Heap applications (Kth largest, median finding)
- [ ] Practice: Heap-based problems

### Week 9: Hash Tables & HashMap
- [ ] Hashing concepts
- [ ] Collision handling (chaining, open addressing)
- [ ] Java HashMap/HashSet implementation details
- [ ] Applications (frequency counting, two-sum)
- [ ] Practice: Hash table problems

### Week 10: Graphs
- [ ] Graph representation (adjacency matrix, list)
- [ ] BFS and DFS algorithms
- [ ] Shortest path algorithms (Dijkstra's)
- [ ] Cycle detection in graphs
- [ ] Practice: Graph problems on LeetCode

## Phase 4: Sorting & Searching Algorithms (Weeks 11-12)
**Goal**: Master efficient sorting and searching techniques

### Week 11: Sorting Algorithms
- [ ] Bubble Sort, Selection Sort, Insertion Sort
- [ ] Merge Sort (divide and conquer)
- [ ] Quick Sort (divide and conquer)
- [ ] Heap Sort
- [ ] Comparison of time/space complexities
- [ ] Practice: Sorting problems

### Week 12: Searching & Advanced Topics
- [ ] Linear Search vs Binary Search
- [ ] Binary Search variations (first/last occurrence)
- [ ] Bit manipulation techniques
- [ ] Trie data structure (optional for interviews)
- [ ] Practice: Searching and bit manipulation problems

## Phase 5: Problem Solving Practice (Ongoing)
**Goal**: Apply knowledge to solve interview-style problems

### Weekly Practice Routine:
1. **Monday-Wednesday**: Learn new topic + solve 2-3 easy problems
2. **Thursday-Friday**: Solve 2-3 medium problems on learned topics
3. **Saturday**: Mixed practice (review week's topics)
4. **Sunday**: Rest or light review

### Problem Sources:
- [ ] LeetCode (start with Easy, progress to Medium)
- [ ] GeeksforGeeks (for explanations)
- [ ] InterviewBit/CodingNinja (for structured practice)
- [ ] Pramp/Mock interviews (later stages)

## Progress Tracking

### Weekly Check-ins:
- [ ] Complete all planned topics for the week
- [ ] Solve minimum 5 problems (2 Easy, 2 Medium, 1 Hard attempt)
- [ ] Review and refactor previous week's solutions
- [ ] Note down patterns and common techniques

### Monthly Milestones:
- **End of Month 1**: Comfortable with Java basics + Arrays/Strings
- **End of Month 2**: Comfortable with Linked Lists, Stacks, Queues, Recursion
- **End of Month 3**: Comfortable with Trees, Heaps, Hash Tables, Graphs
- **End of Month 3**: Able to solve Medium LeetCode problems consistently

## Tips for Success
1. **Consistency over intensity**: Daily 1-2 hours > weekend binge
2. **Understand before coding**: Explain algorithm out loud before typing
3. **Hand trace**: Trace through examples with small inputs
4. **Space-time analysis**: Always consider complexity
5. **Pattern recognition**: Group similar problems (sliding window, two pointers, etc.)
6. **Review regularly**: Revisit solved problems after 1 week, 2 weeks, 1 month
7. **Teach what you learn**: Explain concepts to imaginary rubber duck
8. **Clean code**: Write readable, well-commented solutions from day one
